Result: `bash scripts/check.sh` prints CHECK: PASS (177 tests, ruff clean, pairs.yaml reproducible,
dry-run ok). `config/pairs.yaml` md5 before and after: 21de17439d79817f9cd9b033017b684c (byte-identical,
regenerated by the new package). Nothing committed.

## Files changed
- Major 1: new `tests/test_cli.py` (10 tests: unknown pair -> 2, naive --asof -> 2, held lock -> 3 and the
  foreign lock is left alone, dry-run with the real run functions makes no calls/writes/lock and prints the
  total, `--workers` passed to Polymarket only, `--only`, `--no-backfill`, failures -> exit 1 and listed,
  `report` output from a tmp parquet). RAW_DIR and SCRATCH are monkeypatched; run functions are faked.
  `cli._write_gap_files` lost its unused `tickers` parameter.
- Major 2: `store/raw_views.py` calls `Manifest(m).read()` before each manifest view; `ignore_errors=true`
  stays only for the torn lines `read()` accepted. Tests in `tests/test_ingest.py`: interior corruption
  raises `json.JSONDecodeError`; a torn final line is accepted.
- Major 3: `polymarket.run_polymarket` is now ~25 lines. Logic is in a `_Run` class
  (`process`, `_window`, `_fetch_window`, `_handle_empty`, `_probe_fid1`) plus `_plan_specs`; max nesting 3.
  Duplicated failure block removed (one `_fetch_window` records and logs; probe uses `label="probe "`).
  `common.base_record` / `common.failed_record` are shared; `stocks.run_stocks` uses them; `_fail_rec` is gone.
  Same manifest records, log text, call/sleep order.
- Major 4: new package `src/poly_actor/pairs_build/` (gamma, slugs, calendars, consts, util, fed,
  recession, btc, cpi, emit). `scripts/build_pairs.py` is an 85-line CLI wrapper.
  `GammaClient` (dataclass: cache_dir, refetch, fetch_slugs, injected get/sleep, call_count) replaces the
  globals `REFETCH`, `FETCH_SLUGS`, `_call_count`; every builder takes it explicitly. Gamma calls use
  `ingest.common.request_json_with_retry`. `build_btc` and `build_cpi` are about 35 lines each, split into
  rung / month / summary / snapshot and merge / month-entry / coverage helpers; static prose lives in
  `*_STATIC` module dicts. No function over 60 lines in the new package.
  `tests/test_build_pairs.py` imports updated; new test for retry-through-shared-helper and cache reuse.
