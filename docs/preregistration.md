# Pre-registration (milestone 1, step 2 pairs)

Date: 2026-10-01. Frozen BEFORE any Polymarket price history (CLOB `prices-history`) or any
stock/ETF return series has been looked at for these pairs. Step 2 only touched Gamma
metadata (slugs, token ids, volumes, dates, resolved outcomes). Any change after this point
must be appended as a dated amendment below, never edited in place. The original text is kept as
written; where an amendment conflicts with it, the amendment (section "Amendments") wins.

Source of truth for definitions: `config/pairs.yaml` (generated by `scripts/build_pairs.py`).
Status of that file is still `draft  # pending user approval`; this document freezes the
analysis plan, not the user approval.

Global rules (apply to every pair)
- All timestamps tz-aware UTC. Events roll 1 hour after the real event time (FOMC statement
  14:00 ET, BLS CPI 08:30 ET, BTC month end 00:00 ET), never on Gamma `endDate` or the `closed`
  flag.
- Signals are built from changes; never difference across two events. The bar starting at the
  roll time uses the new event's own 1-hour change and carries `roll_hour=true`; step 6 excludes
  it.
- Hourly lead-lag uses only hours when both series trade (US regular session). Overnight and
  weekend moves are tested separately against the opening gap.
- Primary hypothesis per pair is one test, chosen now. Everything else is exploratory and is
  labelled as such. Multiple-testing control (step 6) is applied across the 4 primary tests.
- A null result is a valid result. Placebo and baseline checks are mandatory where listed.

## Pair 1: `fed_decision` (primary)

- Signal: `fed_expected_change_bp = sum(p_i * delta_i) / sum(p_i)`, delta in bp of the named
  buckets (-75, -50, -25, 0, +25, +50). Open-ended buckets ("50+", "75+", "25+") use the stated
  size. Missing buckets count as 0. Catch-all "another level" bucket (2024-11, 2024-12 only) is
  excluded and hours with its mass above 0.25 are dropped. Dovishness = minus the signal.
- Active event: the next FOMC meeting not yet past its roll time (decision time + 1 hour).
  19 meetings, 2024-11 to 2027-01.
- Tickers: TLT, SPY, XLF (XLF tested as XLF minus SPY).
- Expected signs vs dovishness: TLT positive, SPY positive (weak), XLF ambiguous.
- Analysis: hourly cross-correlation / Granger on spliced hourly changes (market hours only),
  plus an event study around each FOMC decision hour.
- Primary hypothesis: hourly change in dovishness leads or coincides with the TLT hourly return
  with a positive sign at lags 0 to +2 hours, in hours where both trade and excluding roll
  hours and decision hours. Secondary: SPY same; XLF minus SPY exploratory.

## Pair 2: `bitcoin_monthly_ladder` (primary)

- Signal: per hour, among rungs that are open (hour before the rung's `closed_time`) and have
  lifetime volume of at least $1,000: `K_up*` = strike where P(reach) = 0.5 on the up ladder and
  `K_dn*` = strike where P(dip) = 0.5 on the dip ladder, each by linear interpolation of log
  strike in P between bracketing rungs; no extrapolation (hour dropped if 0.5 is not bracketed).
  `ladder_level = exp((ln K_up* + ln K_dn*) / 2)`; `skew = ln K_up* + ln K_dn* - 2 ln S_t`
  with S_t the BTC-USD spot. Months without a dip ladder (2024-11, 2024-12) and the two months
  without an event (2025-03, 2025-12) are excluded.
- Primary signal: hourly change in `ln(ladder_level)`.
- Tickers: IBIT, COIN, MSTR (targets); BTC-USD (REQUIRED baseline, 24/7); XLU (placebo).
- Expected signs: all targets positive; XLU zero.
- Analysis: every regression of target returns on Polymarket changes is run with and without
  BTC-USD spot returns as a control. The question is incremental information beyond spot.
- Primary hypothesis: after controlling for contemporaneous and lagged (1 to 3 hours) BTC-USD
  spot returns, the lagged hourly change in `ln(ladder_level)` has a positive coefficient on
  IBIT hourly return (equity session hours only). Placebo: the same coefficient on XLU is
  indistinguishable from zero. If the coefficient vanishes after the spot control, the verdict is
  "no information beyond spot".

## Pair 3: `us_cpi_inflation` (primary, release-day event study)

- Signal: `implied_cpi_yoy = sum(p_i * c_i) / sum(p_i)` over the merged bucket partition. Edge
  bucket centres are boundary -/+ 0.1. `edge_mass` = edge bucket probability share; hours with
  `edge_mass` above 0.10 are dropped. 2026-01 and 2026-03 merge two companion events
  (rule in `pairs.yaml`). 2026-02 ($0 volume) and 2026-08 (no market) are gaps.
- Method validation (before any returns are examined): implied CPI at release time minus 1 hour
  lies within one bucket width of the winning bucket centre (0.1 pp, edge winners within 0.1 pp
  beyond the boundary) in a majority of resolved months. If not, the method is revised and the
  revision is logged here.
- Tickers: TLT, QQQ. Expected sign vs the change in implied CPI: negative for both.
- Analysis: release-day event study. Pre-release surprise proxy = implied CPI at release minus
  1 hour minus the implied CPI 5 trading days earlier; outcome = TLT and QQQ return from the
  prior close to the 09:30 ET open (opening gap) and the first hourly bar. No hourly lead-lag.
- Primary hypothesis: across releases, the change in implied CPI is negatively related to the
  TLT opening-gap return (sign test and rank correlation).

## Pair 4: `us_recession` (secondary, event study)

- Signal: hourly change in P(Yes) of the active market (2025 market until 2025-10-01 00:00 UTC,
  then the 2026 market).
- Tickers: SPY, IWM, TLT, and the IWM minus SPY spread. Expected signs vs change in P(recession):
  SPY negative, IWM negative, TLT positive, IWM-SPY negative.
- Analysis: event study around the largest absolute daily probability moves only. The 2025
  market resolved No, so this is effectively one episode; no lead-lag inference is claimed and
  no significance claim is made beyond descriptive event windows.
- Primary hypothesis: on days with the largest probability increases, the IWM minus SPY spread
  falls (descriptive; confidence stated as low).
