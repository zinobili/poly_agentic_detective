Branch `claude/fervent-mayer-k4klat`. **No new statistics and no method changes.** Everything
shown comes from `reports/election/results.json` and `reports/election/series/*` (step 9). A
number that is not in the bundle is not shown.

Environment: Linux, `.venv/bin/python`, `.venv/bin/streamlit`.

## Decisions (main, 2026-11-13)
1. A second Streamlit app, `src/poly_actor/election/app.py`
   (`streamlit run src/poly_actor/election/app.py`), separate from the milestone-1 dashboard,
   which stays untouched. Reuse `poly_actor.dashboard.style.page_css` and the look of the
   milestone-1 app (verdict badge, confidence meter, checklist rows, "How to read / So what /
   For experts" on every chart). Follow `docs/design/dashboard_ux.md`.
2. Audience: an investment specialist or trader in AI equities and derivatives. Plain language
   first, the technical line underneath in small type. Every chart title is an action title
   computed from the results (never hard-coded to a result), and never says more than the
   verdict does.
3. Pure functions for text and figures in `election/report_text.py` and `election/charts.py`
   (tested offline against a small fixture bundle in `tests/fixtures/election/bundle/`); the app
   file only lays them out.
4. `docs/election/findings.md` is generated by `python -m poly_actor.election report` from the
   bundle + a prose template with no numbers in it (same rule as milestone 1's findings).
5. Charts: Plotly, two stacked panels on a shared x-axis instead of dual y-axes, colour-blind-safe
   palette, both light and dark theme readable.

## Page structure (a presentation that reads top to bottom)
1. **Headline**: the `headline.sentence`, the question in plain words, and a 2-card scorecard
   (H1, H2) with verdict badge, one-sentence finding, confidence meter.
2. **The set-up**: what happened (Democrats took both chambers; the Senate was the chamber in
   doubt), chart A = the four odds series over the whole life; chart B = cumulative return of
   the AI composite, the four sub-baskets, the placebo basket and RSP.
3. **H1 Was there a partisan beta?** chart = b per +10 points for composite, placebo, difference,
   with 90% CIs; robustness table; MDE stated in plain words ("we could have detected X").
4. **H5 Which part of the AI trade?** chart = b per sub-basket with CIs.
5. **H2 Did the betas predict election night?** scatter of b_i vs event abnormal return, coloured
   by sub-basket, names labelled; H2b walk-forward bars; placebo comparison.
6. **H3 Election night, minute by minute**: stacked panels, odds on top, futures (% from
   18:00 ET) below, shared time axis in ET; lag coefficient chart. Labelled "Descriptive only".
7. **H4 Who moved first?** lag bars with the noise band (same visual as milestone 1 chart 1).
8. **For the derivatives desk (exploratory)**: E2 vol term structure around four elections;
   implied vs realised move; E1 rolling beta.
9. **Other exploratory**: E3 moratorium markets, E5 post-election drift. Each under a visible
   "Exploratory" tag.
10. **How this was done**: four short blocks answering, for this study: what specialists do that
    a casual look misses; which primary sources were used; methods and tools; how usefulness was
    tested (pre-registration, placebo basket, permutation inference, out-of-sample walk-forward,
    MDE). Then limits ("What this does not show") and the disclosure of what was seen before the
    freeze. Prose lives in the template; any numbers come from the bundle.
11. Glossary (collapsed) and "Not financial advice, paper only".

## Rules as examples (each becomes a test)
| Input | Expected |
|---|---|
| Bundle with H1 verdict "Too noisy to tell" | headline and H1 card say so; no chart title contains "beta of" as a claim, "predict", "lead" or "first" |
| Bundle with H1 "AI carried a partisan beta", b > 0 | H1 title says AI names rose when Democratic odds rose, with the size per 10 points from the bundle |
| H2 verdict "Betas did not predict election night" | scatter title says no visible link; so-what says "That's a valid result" |
| Any exploratory block | rendered with an "Exploratory" tag; never appears in the headline |
| H3 block | always carries "Descriptive only: one night, and the futures path was seen before the plan was frozen" |
| Every number token in generated `findings.md` | traces to a value in `results.json` (same test idea as milestone 1) |
| Missing bundle | the app shows one clear message with the command to build it; no stack trace |
| `streamlit run ... --server.headless true` on the real bundle | starts, HTTP 200, no exception in the log |
